# NoDesk 桌面宠物：碰撞、晕眩、探头、弹射与外观精修

状态：设计已确认，待实现。日期：2026-10-03。基于 [Nono](2026-10-03-nodesk-desk-pet-design.md) 和 [Momo](2026-10-03-nodesk-desk-pet-momo-design.md) 两份设计。

## 地形

`Terrain` 新增 `blocks`，记录每个可见组件的完整矩形 `{ id, left, top, right, bottom }`，可见性的过滤规则和平台相同。弹跳和探头都用这份数据。

## 1. 宠物间碰撞

`resolveCollisions(pets)` 是纯函数，每帧在社交协调器之后运行，返回调整后的宠物和发生碰撞的宠物 id 列表。

- **不参与检测的情况**：被拖拽的宠物；贴在墙上、挂在底边或正在探头的宠物；叠罗汉的上下两只。
- **重叠判定**：两只的水平距离小于两者半宽之和的 0.8 倍，同时垂直距离小于半高之和的 0.8 倍，就算重叠。如果垂直距离超过阈值的 55%，说明是从上往下落，交给头顶平台处理，不算碰撞。
- **两只都站在平台上**：沿水平方向各推开一半的重叠量，两只都进入 `ouch`（0.35 秒，被挤扁，`> <` 表情），朝被推开的方向站着，并清掉当前的行走目标。已经处于 `ouch` 的宠物只推开、不重复记一次碰撞。
- **至少一只在空中**：沿两只中心连线的法向交换速度分量，恢复系数 0.6。原本站着的那只会离开平台：相对速度超过 900 时进入翻滚（`tumble`），否则进入下落（`fall`）。相对速度超过 1100 时，两只都晕 2.5 秒。
- **说话**：碰撞时，被碰撞的宠物说「哎哟」。每只宠物在 5 秒内最多说一次。

## 2. 晕眩

- `PetState.dizzyFor` 表示剩余的晕眩秒数，每帧递减。渲染时只要它大于 0，就把 `data-dizzy` 设为 `true`：眼睛变成蚊香圈，头顶有三颗星星在转。
- 站在平台上并且处于 idle、walk、run 或 happy 时，如果还在晕，姿态就换成 `dizzy`：左右摇晃，不做任何决定。晕眩结束后恢复 `idle`。
- **甩动检测**：`feedShake` 记录拖拽轨迹。水平或竖直方向上，速度超过 900 px/s 时改变方向，就算一次换向。1.2 秒内换向 4 次即判定为晕眩，宠物会晕 3 秒。
- 宠物刚开始晕的时候会说一句，从「晕乎乎…」「眼冒金星～」「别晃啦！」里随机选。

## 3. 躲在组件后面探头

- 新增 surface 类型 `{ kind: 'peek', id, side: 'left' | 'right' | 'top' }`，并在 `PetState.peek` 里记录 `{ offset, tuck, until, wait }`。
  - `offset`：沿边的位置。
  - `tuck`：缩回的程度，0 表示探出，1 表示完全躲好。
  - `until`：剩余的探头时间。
  - `wait`：还要躲多久才能再探出来。
- **露出多少**：从左右边探头时，最多露出身体宽度的 38%；从顶边探头时，最多露出身体高度的 60%，正好露出眼睛。宠物落在组件矩形里的部分用 `clip-path` 裁掉，看起来就像躲在组件后面。
- **怎么过去**：在 `decide` 里新增一个权重 0.08 的分支，随机选一个组件和一条边。
  - Nono 飞过去。
  - Momo 用一个弧度更大的跳跃过去，距离不能超过它的跳跃范围；超出范围时，这次就不探头。
  - 到达时是完全躲好的状态，等 0.6 秒再探出来。
- **探头时的行为**：
  - 探出的速度较慢，大约 0.9 秒；缩回很快，大约 0.25 秒。
  - 鼠标进入 120px 范围内会立刻缩回，躲 1.5 到 3 秒。
  - 探头 6 到 12 秒后跳出来离开。从侧边探头时，侧向跳出后落下；从顶边探头时，往上跳出，落到组件顶上。
  - 有新目标（打开面板）或者桌面要睡觉时，会立刻跳出来。
- `PetInput` 新增 `pointer` 字段，表示鼠标的当前位置。

## 4. 外观精修

- **尺寸**：Nono 改为 48×42（手机端 36×32），Momo 改为 50×44（手机端 38×34）。
- **共同改动**：
  - 身体用径向渐变，增加高光和底部边缘的反光。
  - 眼睛更大，有两个高光点。
  - 脚下加一个椭圆阴影，在空中、贴墙、探头和被拖拽时隐藏。
- **Nono**：头顶加一片会摆动的小叶芽，两侧各一只小短手，探头时手会抬起来扒着边。
- **Momo**：两颊加一圈蓬毛，加白色的嘴部，白肚皮；红色项圈上挂一个金色铃铛，跳跃和开心时铃铛会晃；尾巴带条纹和白色尾尖；脚底有粉色肉垫；探头时会露出两只爪子。
- **新增表情**：
  - 蚊香眼：晕眩时显示，优先级最高。
  - `> <`：碰撞吃痛时显示。
  - 翻滚时显示开心眼；如果正在晕，就显示蚊香眼。

## 5. 弹射与弹跳

- **拉弓**：拖拽时调用 `dragTo(s, x, y, bounds)`，把宠物中心限制在离屏幕边缘至少半个身体宽度的位置。超出的部分记为张力 `tension`，长度上限 240px。
  - 渲染时，宠物会沿张力方向被拉长，最多拉长 60%、压窄 25%。
- **发射**：松手时，如果张力长度超过 30px，就进入翻滚。速度方向和张力相反，大小是张力长度的 14 倍，上限 2600。
  - 不是拉弓、但直接用力扔出去的速度超过 1800 时，也会进入翻滚。
  - 发射时宠物会说「咻——！」。
- **翻滚（`tumble`）**：宠物按半径为 `min(宽, 高) / 2` 的圆形处理。
  - 重力是平时的 0.85 倍。
  - 碰到组件矩形的四条边或屏幕的四条边都会反弹，恢复系数 0.72；在屏幕底边上额外有 8% 的摩擦。
  - 渲染时，宠物会随水平速度旋转。
  - 单次撞击时法向速度超过 1100，就晕 3 秒。
- **结束**：翻滚超过 0.5 秒且速度低于 220 时，转为普通下落，旋转角度归零，之后按正常规则落到平台上。

## 测试

- **模型**：
  - `blocks` 的提取。
  - 地面碰撞的推开和 `ouch`；叠罗汉的两只不算碰撞；空中撞到站着的会把对方撞飞并且都晕。
  - 甩动检测；晕眩期间不动、到时间后恢复。
  - 拉弓的张力和发射；用力扔出去会翻滚。
  - 翻滚时撞到组件侧边和屏幕顶边会反弹，撞得重会晕；翻滚最终会落地。
  - 探头：能到达位置、会探出来、裁剪的数值正确、鼠标靠近会缩回、时间到了会跳出来；Momo 够不着时不探头。
- **浏览器实测**：
  - 甩宠物会晕。
  - 拉到屏幕外再松手会弹射，弹跳之后能落地。
  - 两只宠物不会重叠。
  - 探头时只露出一部分，鼠标靠近会躲回去。
