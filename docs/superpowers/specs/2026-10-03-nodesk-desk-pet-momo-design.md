# NoDesk 第二只桌面宠物「Momo」与双宠互动设计

状态：设计已确认，待实现。日期：2026-10-03。基于 [Nono 设计](2026-10-03-nodesk-desk-pet-design.md)。

## 目标

在 Nono（会飞的团子）之外，再加一只能力互补的橘白小猫 Momo。两只同时在桌面上活动，并且会互相打招呼、追逐、一起睡觉和叠罗汉。设置里可以分别开关两只。

## 形象

- Q 版小猫，头和身体连成一团，约 46×40，手机端 36×31。
- 橘色渐变（`#ffd09c` → `#f29a4b`），白色的嘴部和肚皮，额头三道深橘色条纹。
- 三角耳朵，内侧粉色；胡须；粉色小鼻子和「ω」形嘴；白色小脚；一条会摆的卷尾巴。
- 表情眼睛和 Nono 共用四套：普通、开心、睡觉、惊讶。没有翅膀。
- 调暗模式下整体降低亮度。

## 物种能力

新增 `Species` 配置，Nono 和 Momo 各一份：

| | Nono | Momo |
|---|---|---|
| 会飞 | 是 | 否，掉落时不滑翔 |
| 走 / 跑 / 爬（px/s） | 40 / 110 / 30 | 45 / 160 / 60 |
| 跳跃水平 / 上升上限（px） | 260 / 160 | 380 / 300 |
| 爬墙权重 | 0.10 | 0.15 |

Momo 不会飞。要去够不着的平台时，它会按跳跃能力在平台之间做广度优先搜索，找出下一跳的平台。如果离起跳点太远，就先跑到当前平台靠近下一跳的边缘，再跳过去，这样一跳一跳地前进。找不到路线时，普通的闲逛目标直接放弃；但回时钟睡觉和去打开的面板这两种目标，Momo 会不顾跳跃上限，直接大跳过去。因为手机布局里 dock 和时钟之间没有可以中转的平台，没有这条规则 Momo 就回不了时钟。每个目标最多尝试 20 秒，超时就放弃。

## 宠物头顶也是平台

- 每只宠物站在平台上（不在空中，也没有被拖拽）时，它头顶会生成一个平台 `pet:<id>`，宽度是身体宽度的 80%。
- 其他宠物落地检测时会把这些平台算进去，所以可以跳到或者被扔到另一只头上。
- 站在头顶的宠物跟随下面那只水平居中，所以会被驮着走。下面那只一旦离开平台（起跳、被拖拽），头顶平台就消失，上面那只随之掉落。
- 不允许循环叠：A 站在 B 头上时，B 看不到 A 的头顶平台。
- 站在头顶时不会走路或爬墙。每 2 到 4 秒做一次决定：要么张望，要么侧向跳下去。

## 互动（社交协调器）

`desk-pet-social.ts` 是纯函数 `socialStep(pets, social, dt, terrain, input, rng)`，每 0.3 秒检查一次。宠物数量少于 2、桌面在睡觉或开启了 reduced motion 时不做任何事。下面说的「空闲」，指宠物站在普通平台上，姿态是 idle、walk 或 run，没有目标，也不在飞。

- **打招呼**：两只都空闲、在同一个平台上、水平距离小于 70px 时，两只都进入 `happy` 并面向对方。先说话的一只立即说一句，另一只 1.2 秒后回一句。冷却 25 秒。
  - Nono 的台词：「嗨 Momo～」「一起玩吗？」「今天也很可爱嘛」
  - Momo 的台词：「喵～」「嗯！」「喵呜～」
- **叠罗汉**：两只都空闲、在同一个平台上、距离小于 90px 时，每次检查有 8% 的概率触发。随机选一只作为上面那只，它跳向另一只的头顶，并说「嘿咻！」。下面那只原地停 2.5 秒等它落稳。冷却 45 秒。
- **追逐**：每隔 60 到 120 秒，如果两只都空闲，就随机挑一只做追的一方。追的一方说「等等我！」，被追的一方 0.9 秒后说「抓不到～」并开始逃跑。
  - 逃跑方式：一半概率沿平台往远离对方的一端跑；另一半概率换到另一个平台，Nono 是飞过去，Momo 是一路跳过去。
  - 追的一方：和对方在同一个平台上时就朝它跑过去；不在同一个平台时，把对方所在的平台设为目标。
  - 被追的一方空闲时，如果对方在同一个平台上、离自己不到 120px，会再逃一次。
  - 结束条件：在同一个平台上距离小于 36px 算追上，两只都 `happy`，追的一方说「抓到啦！」；超过 12 秒没追上则作罢。结束后重新安排下一次追逐的时间。
- **一起睡觉**：模型输入新增 `restSlot`。两只时 Nono 取 -1、Momo 取 +1，只有一只时取 0。睡觉位置是时钟中心加上 `slot × 0.8 × 自身宽度`。宠物到达时钟后，如果离自己的位置还远，就先走过去再睡。

## 渲染

- `desk-pet.tsx` 改为 `DeskPets`，接收要显示的物种列表。由同一个 rAF 循环依次推进每只宠物，每只宠物的地形里都加上其他宠物的头顶，然后运行社交协调器。
- 每只宠物有自己的元素、气泡和拖拽处理，并标上 `data-species`。
- 闲聊和问候由第一只宠物说。有新通知时，所有宠物一起 cheer，由第一只说话。

## 开关

- localStorage 新键是 `nodesk.ambient.pets.v2`，值为 JSON `{ "nono": boolean, "momo": boolean }`，默认两只都开。
- 如果旧键 `nodesk.ambient.pet.v1` 的值是 `false`，迁移为两只都关。
- 设置中心「桌面宠物」区域改成两个开关：「显示 Nono」「显示 Momo」。

## 测试

- **模型**：
  - Momo 掉落时不滑翔，Nono 会滑翔。
  - Momo 能一跳一跳到达远处的平台；目标够不着时会放弃。
  - 能落到另一只的头顶；下面那只走动时会驮着走；下面那只离开平台时上面那只会掉下来；站在头顶的会自己跳下来。
  - 两只睡觉时一左一右，互不重叠。
- **社交**：打招呼、睡觉时不互动、追逐的开始和逃跑、追上、超时、跨平台追逐、叠罗汉（从起跳一直模拟到落在对方头顶）。
- **偏好**：默认值、旧键迁移、损坏的 JSON。
- **契约**：工作台和设置中心的接线。
- **浏览器实测**：两种视口下截图，确认两只都可见、都能站在组件上；检查两只能各自拖拽；检查调暗后两只分别睡在时钟两侧。
