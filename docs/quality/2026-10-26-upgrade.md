# 2026-10-26 依赖、安全与 UI 升级记录

接续已有工作区升级，补齐遗漏的 NoDesk 安全更新、NoStar 上游修复及跨应用 UI 细节。以下记录提交部署前的验证结果。

## 依赖与安全

`npm run audit:all` 对根工作区、NoDesk、NoMoney、NoStar 四套独立锁文件的最终结果均为 **0 个已知漏洞**（包含开发依赖）。这表示审计数据库当前没有匹配的公告，并非对所有业务逻辑的安全保证。

NoDesk 本轮开始时有 16 条依赖安全公告（2 critical、5 high、7 moderate、2 low）。升级 Next 16.4.3、OpenNext 1.20.13、Wrangler 4.152、React 19.3.1，并更新 body-parser、sharp、undici、glob 等限定版本范围的覆盖。移除没有代码引用的 jsrsasign 及其类型包。冻结锁文件安装和 peer 检查通过。

其他应用同步更新 Fastify、Prisma、Vue、Vite、Vitest、DOMPurify、KaTeX 等依赖和锁文件。Vue 工具链保留 TypeScript 5.9.3；NoStar 分别使用原生 TypeScript 7 做类型检查和 TypeScript 6 JavaScript API 支持 ESLint。Mermaid 保留兼容的最新 11.x，原因见 [NoStar 第三批说明](../deployment/nostar-batch-three.md)。

## UI 与同步行为

- NoDesk：补齐弹窗可访问名称、Tab 焦点约束、关闭后焦点返回、嵌套弹窗 Escape 顺序和滚动锁；减少动态效果；改善表单、图片和工作台细节。
- NoMoney：提高浅色主题辅助文字及到期状态对比度；金额增加千位分隔并统一负号位置；完善抽屉安全区、焦点和关闭行为，并将抽屉挂载到页面根层，避免父容器间距使其偏离视口；移动端“更多”菜单支持方向键并在焦点离开时关闭；国家选择框先关闭选项，再允许 Escape 关闭抽屉。
- NoNo：续费金额弹窗接入现有键盘、Android 返回键和焦点生命周期；账户日期随语言切换，时区继续使用上海时间。
- NoStar：移植 README 图片、近全屏弹窗及 WebDAV 修复；统一真实 GitHub ID 与旧时间戳 ID 的认领规则，保留 AI 分析、分类、订阅和 Release 已读状态；旧基线和备份导入使用同一身份整理。详细适用范围、迁移及 JSON 历史映射限制见 [说明](../deployment/nostar-batch-three.md)。

## 部署与验证边界

部署需要先执行 Prisma 迁移 `20261026203000_nostar_repository_identity`。迁移将仓库名称唯一索引改为普通索引，保留 GitHub ID 唯一约束和现有数据；恢复旧唯一索引前需先处理重复名称。按既有部署流程备份和迁移即可。

当前容器没有 Android JDK/SDK，未重跑 Android 构建；未部署 Cloudflare Worker 或连接生产数据库，也未向真实 GitHub 收藏/Lists 写入数据。OpenNext 的 Node.js middleware 仍有实验性支持提示。需要生产环境的 E2E 用例按既有条件跳过，不能视为线上验收完成。
