# NoStar 第二批与 UI

基于第一批 `48dd178`，继续沿用 NoNo 登录、服务端加密 GitHub Token、按用户存储及统一主题。

- 批量 Star：从文本、Markdown、GitHub 链接提取并去重仓库，每批最多 100 个；先加载元数据和 README 预览，再明确执行。最多 5 个并发请求，取消停止等待队列，已经确认成功的请求仍保存。变更请求不自动重试。粘贴历史按 NoNo 用户保存，过滤疑似凭据。
- GitHub Lists：通过现有浏览器会话 GraphQL 代理读取，分页和并发均有限制。支持导入为本地分类、编辑本地成员、映射现有 Lists 或创建私有 List，并预览推送。默认保留远端成员，移除成员必须明确选择；不取消 Star。保留其他 Lists 的归属以及导入的非本地仓库。远端快照、本地分类依据、账号或仓库规范名称变化时阻止过期推送；失败不自动重放。
- 外观与卡片：独立开关描述、标签、语言、Star 数、许可证和更新时间；小、默认、大字号及减少动画。手机卡片操作放入可键盘操作的折叠菜单。偏好与 Lists 映射进入按用户的本地保存、后端同步、手动导入导出和 WebDAV 备份。
- README：GitHub 提示块、KaTeX 行内及块公式、延迟加载的 Mermaid。图形按严格模式渲染后再次清洗，失败显示源码；保留代码复制、相对资源路径和双语阅读。重资源不进入初始包。
- 弹窗：共享焦点循环、焦点恢复、顶部弹窗 Escape 处理和滚动锁；覆盖 README 及图片放大。修复严格模式下设置入口跳转及账号切换时延迟保存跨用户的问题。

## 数据迁移与部署

迁移 `20260930140500_nostar_repository_license` 仅向 `NoStarRepository` 增加三个可空文本字段：`licenseKey`、`licenseName`、`licenseSpdxId`。旧客户端没有提供许可证时保留现有值；之后刷新 GitHub 元数据会补齐旧仓库的许可证。其他新增设置存入现有用户设置 JSON。

部署使用既有 `deploy-compose.mjs`：锁定部署、建立安全快照、执行迁移、候选实例与公开入口验收。核对部署前后用户、书签和 NoStar 仓库数量；迁移记录预期增加一条。

## 验证范围

覆盖解析、用户隔离、取消与部分失败、分页界限、Lists 成员保留和过期预览、偏好同步、许可证往返、README 清洗及嵌套弹窗。运行 NoStar 完整测试、类型检查、ESLint、生产构建、体积检查、依赖审计和服务端测试；Chromium 桌面与手机测试包含批量预览、Lists 导入/本地编辑、README 公式/图形和外观切换。

浏览器 GitHub 请求使用受控响应验证，未对用户真实 GitHub 收藏或 Lists 执行测试写入。GitHub 在线功能仍受 Token 权限和服务额度影响。
