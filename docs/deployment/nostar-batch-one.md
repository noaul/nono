# NoStar 第一批上游改进

本批沿用 NoNo 登录、加密凭据、多用户数据隔离及现有导航，无数据库结构迁移。

- TypeScript：类型检查显式运行原生 7.0.2；ESLint 的 JavaScript 编译器 API 使用 6.0.3。独立锁文件保留两套编译器。
- WebDAV：在线时使用 NoNo 服务端已保存配置的代理，浏览器只发送配置 ID；代理保留 XML、JSON 原文及 HTTP 状态。连接、目录、下载和上传设置不同超时，覆盖响应体读取。离线直连需要真实本地凭据。
- 备份：新增 Release 订阅、来源、已读状态、分类覆盖及顺序、资源筛选器、活动配置和翻译引擎。旧备份缺少新增字段时保留现有偏好；隐藏密钥的备份不会覆盖已有密钥。
- 翻译：改用现行 Microsoft Edge 接口，可在通用设置选择 Google。大段落分块后按原输入顺序合并，保护行内代码，支持超时、取消及瞬时错误重试。两者均依赖外部公开接口的可用性。
- AI：同一用户、配置和端点在当前浏览器运行实例共享并发和每分钟请求限制；429 按 Retry-After 冷却，三次请求失败后停止，批量取消会停止所有工作线程及排队等待。限制不协调多个标签页或多个用户共享的服务端密钥。
- Release：增量刷新同时检查最新已有发布的说明及资源变化；实际内容变化重新标为未读，下载计数变化不触发。筛选器支持关键词黑名单、始终包含仓库、始终排除仓库，多筛选器按 OR 合并。设置沿用按用户存储的 JSON。

参考上游：GithubStarsManager 0.8.4，源码比较基于 `155d71516c475689f4dfa4ebe88998cab15b5aee`。本批为 Web 适配，未加入 Electron 插件或更新器。

验证：NoStar 单元/组件测试、TS 7 类型检查、ESLint、生产构建、包体积检查和审计；服务端代理、鉴权与网络测试；现有部署验收脚本用于 nc48 的 Compose 部署。
